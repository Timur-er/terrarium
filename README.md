# Террариум

Регион из нескольких куполов на чужой планете: в каждом четыре десятка колонистов с характером, памятью,
отношениями и слухами живут сами, между куполами ездят снабженцы и переселенцы, а игрок наблюдает,
подкидывает события и шепчет цели. Архитектура и замысел — в `terrarium-architecture.md`.

## Язык игры

Весь игровой текст, интерфейс, состояние для модели, промпты System Two, сценарии и отчёты — на английском:
Jev обучен в основном на английском и на нём отвечает точнее. Имена колонистов и куполов тоже английские.
Документация в этих README остаётся на русском.

## Части

| папка | что | как запустить |
|---|---|---|
| `client/` | интерфейс (Vite + React + three.js) с встроенным движком мира | `cd client && npm install && npm run dev` → http://localhost:5173 |
| `server/` | сервер региона на Node: тот же движок, WebSocket, сохранение, System Two | `cd server && npm install && cd .. && npx --prefix server tsx server/index.ts` → ws://localhost:8787 |
| `brain/` | сервис мозга System One на Python: кости, Claude, локальная модель; 20 сценариев | `python3 -m venv brain/.venv && brain/.venv/bin/pip install -r brain/requirements.txt && BRAIN_BACKEND=random brain/.venv/bin/uvicorn brain.server:app --port 8765` |

Клиент работает сам по себе: мир крутится в вкладке. Кнопка «мир: локально» в верхней панели подключает
его к серверу, тогда мир живёт на сервере, а вкладка становится зрителем и пультом. Кнопка «мозг»
переключает, кто принимает решения: эвристика движка, кости или сервис мозга.

## Как это устроено

```
клиент (браузер)  ──WebSocket: снапшот + дельты──▶  сервер мира (Node, движок TS)
      │                                                    │            │
      │ команды: скорость, карта, шёпот,                   │            ▼
      │ наблюдать, спросить                                │     System Two (LLM, не в hot path):
      │                                                    │     дневники, хроника дня, «почему?»
      ▼                                                    ▼
   3D-сцена, панели                     мозг System One: decide(state, questions)
                                        ── heuristic | random | remote ──▶ brain/ (Python)
```

- **Движок** (`client/src/sim/`): тик = игровая минута, потребности, A*, восприятие, триггеры, меню действий
  с предусловиями, сэмплирование, память трёх слоёв, слухи с искажением, дрейф характера, стройка, свадьбы.
- **System One**: состояние собирается словами (`state.ts`), вопросы двухступенчатые плюс внутренние
  (`brain.ts`), ответы приходят распределениями. Протокол общий для клиента и сервиса.
- **System Two** (`server/reflect.ts`): раз в игровой день на персонажа дневник и правки целей, отношений,
  черт, убеждений; раз в день на мир хроника из лога; по запросу ответ от лица персонажа. Нужен
  `ANTHROPIC_API_KEY` в окружении сервера, иначе часть выключена и дневники остаются шаблонными.

## Прогон с Jev (System One от TypeSafe)

Мозг System One в игре устроен под Jev: состояние персонажа словами плюс типизированные вопросы
`choice` / `score` / `noul`, ответ с вероятностями и уверенностью. Бэкенд `jev` в `brain/backends.py` шлёт это в
`POST https://api.typesafe.ai/v1/systemone` почти без перевода: варианты становятся `criteria` выбора, диапазон
оценки превращается в уровни, внутренние вопросы идут как `noul`.

**1. Ключ.** Скопируйте `.env.example` в `.env` в корне проекта и впишите `TYPESAFE_API_KEY=…` (ключ из
console.typesafe.ai/keys). Файл читают и сервис мозга, и скрипт прогона; в git он не попадает.

**2. Сервис мозга** (один раз: `python3 -m venv brain/.venv && brain/.venv/bin/pip install -r brain/requirements.txt`):

```bash
BRAIN_BACKEND=jev brain/.venv/bin/uvicorn brain.server:app --port 8765
```

`GET http://localhost:8765/health` покажет бэкенд, число решений, латентность и потраченные токены;
`GET /log?limit=50` — последние обращения: состояние, вопросы и ответы Jev.

**3. Проверка на сценариях** (20 ситуаций с ожидаемым поведением, без игры):

```bash
brain/.venv/bin/python -m brain.eval --backend jev --verbose
```

**4. Прогон мира на несколько солов** с отчётом (во втором терминале, сервис мозга должен работать):

```bash
npx --prefix server tsx server/run.ts --sols 3 --domes 1 --brain remote --out report/jev
```

Один сол это примерно 800 решений, то есть 800 обращений к Jev; при 100–500 мс на ответ сол занимает
2–7 минут, три сола укладываются в четверть часа и стоят центы. В папке отчёта: `report.md` (сводка, хроника,
громкие события, примеры решений с распределениями), `log.txt`, `decisions.jsonl` (каждое решение с состоянием),
`brain-calls.json` (журнал обращений с вероятностями и уверенностью Jev), `diaries.md`, `stats.json`.
Если в `.env` есть ещё и `ANTHROPIC_API_KEY`, System Two напишет настоящие дневники и хронику дня.

Для сравнения тот же прогон можно сделать с эвристикой (`--brain heuristic`) или костями
(`BRAIN_BACKEND=random` у сервиса): разница в поведении колонии и есть материал для выводов.

## Переменные окружения сервера

`PORT` (8787), `SPEED` (0/1/3/10/30), `BRAIN` (heuristic | random | remote), `BRAIN_URL`
(http://localhost:8765/decide), `ANTHROPIC_API_KEY`, `SYSTEM_TWO_MODEL` (claude-opus-5).
Мир сохраняется в `server/data/world.json` раз в минуту и при остановке.

## Эксперимент (форк мира)

Кнопка «эксперимент» в верхней панели. Мир копируется в две ветки на одних и тех же костях: ветка А
живёт без вмешательства, в ветке Б вы подкидываете карту и/или шёпот. Обе ветки прогоняются на 1, 3 или
7 солов вперёд за доли секунды, главный мир не трогается. Результат: статистика веток, громкие события
каждой и список колонистов, чьи судьбы разошлись (уехал, погиб, обзавёлся семьёй, разбогател, нажил врагов,
новая цель). Работает и локально, и через сервер (`client/src/sim/experiment.ts`). В форке решает
эвристический мозг, потому что ветки считаются синхронно.

## Мультиплеер

Сервер авторитетный, вкладки — зрители и пульты. При подключении вы получаете имя (меняется в диалоге
«игроки») и валюту «влияние»: 20 на старте, плюс один за каждый игровой час присутствия.

- **Общий аквариум.** Все смотрят один мир. Карты стоят влияния (от 3 до 8), чужой шёпот 2. Кто что
  подкинул, видно в тостах у всех.
- **Подопечные.** Кнопка «[ под опеку ]» в карточке колониста. Один подопечный на игрока, занятого
  взять нельзя. Шёпот подопечному бесплатный и ложится крепче. Таблица считает положение подопечного:
  друзья, доверие, кредиты, должники, роль администратора.
- **Предсказания.** Каждое утро в 06:00 сервер задаёт вопросы дня: кого первым поймают на краже, кто
  первым ударит, сколько разойдётся слухов. Ставка от 1 до 5 влияния, коэффициенты ×2.5–×3, разрешение по
  журналу мира или в 22:00. Точность копится в таблице.

- **Голосование за события.** Три раза в день, в 10:00, 14:00 и 18:00, зрителям купола предлагают три
  случайные карты из колоды (для карт с целью сервер сам выбирает колониста) и вариант «ничего». Полоска с
  вариантами висит над сценой 75 секунд по настоящим часам, голосовать можно один раз и передумать. Победившая
  карта разыгрывается бесплатно, её оплачивает толпа; те, кто голосовал за победителя, получают по единице
  влияния. Если никто не голосовал, событие не разыгрывается. Голосуют только представившиеся; каждый купол
  голосует отдельно. `VOTE_SECONDS` в окружении сервера меняет длительность.

Игроки и рынки сохраняются в `server/data/players.json`.

## Регион из нескольких куполов

Мир — это регион (`client/src/sim/region.ts`): от трёх до пяти куполов на одной планете, каждый —
полноценный мир того же движка со своей картой и жителями. Число куполов, имена (из пула двенадцати),
координаты и сеть дорог выводятся из сида: купола рассыпаются по равнине не ближе 88 и не дальше 132 клеток
друг от друга, дороги тянутся к ближайшим соседям, не пересекаются, не проходят сквозь третий купол и всегда
связывают регион в одно целое; часы пути считаются от расстояния (обычно 6–11). Идентификаторы людей и модулей
префиксуются буквой купола, поэтому уникальны на весь регион.

- **Дороги.** Кто уходит из колонии через шлюз, оказывается на дороге и через несколько часов входит в
  соседний купол, где пробует осесть. Раз в два дня в 08:00 снабженец берёт товар и едет к соседям на день,
  а возвращается с деньгами и чужими слухами: истории про людей, которых здесь никто не знает,
  пересказываются как байки из другого купола, без последствий для репутации.
- **Призраки.** Уехавший оставляет в родном куполе «призрака» с пометкой `left`, чтобы слухи, отношения и
  хроника могли его называть. При возвращении призрак заменяется живым человеком.
- **Камера.** Кнопка «[ купол: … ]» в верхней панели открывает карту региона: купола, дороги, кто в пути.
  Щелчок по куполу переносит камеру, остальные купола продолжают жить. В 3D соседние купола видны на
  горизонте с грубым силуэтом застройки, по дорогам между ними ездят роверы.
- **Сервер.** Регион целиком живёт на сервере (`server/data/region.json`; переменная `DOMES` задаёт число
  куполов, без неё его выбирает сид). Каждая вкладка смотрит один купол и получает его снапшот и дельты плюс компактную сводку
  региона. System Two размышляет только над куполами, на которые кто-то смотрит. Подопечный может жить в
  любом куполе, ставки задаются на каждый купол отдельно и показываются для того, который вы смотрите.
- **Новые купола.** Когда под куполом тесно и невесело (от 44 жителей, шестеро недовольных или бездомных),
  кто-нибудь общительный и смелый собирает партию из 4–7 человек: недовольных, бездомных, свою семью, друзей.
  Разведка выбирает площадку рядом с родным куполом по тем же правилам, что и при генерации региона, и
  прокладывает к ней дорогу (и вторую к ближайшему соседу, если помещается). На карте появляется
  стройплощадка, партия едет по дороге, и с прибытием первого переселенца поднимается новый купол: склад,
  пищеблок, мастерская, реактор и три жилых модуля, остальное придётся строить. Основатель становится
  администратором, семьи занимают модули вместе, кому места не хватило, копит на свой. В родном куполе
  остаются память об ушедших и запись в хронике. То же самое можно шепнуть любому взрослому:
  «основать новый купол». Всего в регионе не больше восьми куполов.
- **Склады и торговля.** У каждого купола склад: пайки и детали. Каждое утро в 06:00 агрономы растят
  пайки, механики и монтажники собирают детали, пищеблок и ремонт систем берут своё, а цены следуют за
  запасом (паёк от 1 до 4, детали от 2 до 5). Покупки в пищеблоке и баре тратят пайки; когда склад пуст,
  еду не купить, и голод толкает к кражам. Стройка расходует детали, без них ползёт втрое медленнее.
  Раз в два дня снабженец грузит излишки (пайки сверх двухдневного запаса, детали сверх двадцати) и
  едет к соседу, где они дороже, сдаёт на склад, а обратно везёт то, что там в избытке; снабженец
  получает долю с оборота. В диалоге региона видны склады и цены всех куполов и кнопка «караван сюда»:
  сосед с излишками отправляет снабженца немедленно (по серверу это стоит 3 влияния). Ночью роверы не
  выходят. Новый купол начинает с 24 пайков и 10 деталей, так что первые дни живёт на караванах.
- **Форк мира** копирует только текущий купол: дороги и соседи в эксперименте не участвуют.

## Графика: набор моделей glTF

Здания, камни снаружи купола, ровер и шлюз собираются из моделей Kenney Space Kit (CC0, `client/public/assets/kenney/space/`,
лицензия рядом). Загрузчик и рецепты в `client/src/scene/kit.ts`: для каждого типа здания список деталей
(главная модель вписывается в участок, остальные ставятся рядом или сверху), материалы Kenney перекрашиваются
в палитру колонии, полоса `metalRed` получает цвет здания и светится ночью. Пока набор грузится, здания
рисуются процедурно, как раньше; `__renderer.useKit = false` и `refreshBuildings()` возвращают старый вид.
Следующие шаги: персонажи с ригом и анимацией (Blender или Mixamo), портреты и иллюстрации карт.

**Режим «мозаика»** (кнопка ▦ в углу сцены, запоминается в браузере): пробный стиль по референсу,
где мир выложен мелкой плиткой, цвет выбелен, по краю купола геометрия распадается на квадратные ячейки, а в
космос уплывают пиксели. Сделано шейдерной вставкой в стандартные материалы (`client/src/scene/mosaic.ts`):
сетка в мировых координатах по доминирующей нормали, растворение по расстоянию от центра, светящиеся
вещи (окна, акцентные полосы, лампы) сохраняют цвет. Трава в этом режиме прячется.
